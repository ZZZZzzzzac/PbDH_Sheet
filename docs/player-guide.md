# 车卡器教程与技巧

## 快速开始

1. 在右上角「系统包」中选择游戏系统。如果预设系统包中没有你想要的系统包，请上传(zip或目录皆可)。
2. 打开「玩家功能 → 车卡指引」，跟随提示填写人物卡，或自己手动进行填写。
3. 完成后运行「玩家功能 → 车卡检查」，查看漏填或不合法的内容。在导出前会自动运行一次检查功能。
4. 检查功能会对一些基础规则进行数值计算和检查，但即使报错仍可以点击「继续」开始导出。

人物卡会自动保存在当前浏览器。换设备、换浏览器或清理网站数据前，请用「导入导出 → 导出 PbDH」下载备份。

## 容易忽略的操作

触屏设备没有右键：下文所有右键操作均可改为长按约半秒。

### 数值与标记

- 普通数字：点 `-` / `+` 调整数值；也可直接点击数字输入。
- 图标或圆点等标记：左键点 `-` / `+` 调整当前值。
- 系统允许修改上限时：右键点 `-` / `+` 调整上限。
- 已填写的文字会显示为排版后的内容；点击文字即可重新编辑。
  - 加粗：`**文字**`
  - 斜体：`*文字*`
  - 加粗斜体：`***文字***`
  - 颜色：`:red[文字]`。还支持 `orange`、`yellow`、`green`、`blue`、`purple`、`gray`。

### 卡牌桌面

- 拖动卡牌调整位置。点击或拖动卡牌，会把它移到最上层。
- 右键卡牌打开操作菜单，可查看放大详情、旋转、恢复竖置、翻面、切换状态、添加指示物或删除卡牌。没有背面的卡牌不会显示翻面操作。
- 「大小」滑块统一调整桌面上的卡牌尺寸。
- 卡牌太乱时，点「整理」自动重新排列。

### 卡牌指示物

- 先右键卡牌，选择「添加指示物」。每张卡牌最多放 10 个。
- 左键点指示物：数量 `+1`。
- 右键点指示物：数量 `-1`。
- 指示物为 `0` 时再右键一次：删除该指示物。
- 使用键盘时，`+` / `↑` 增加，`-` / `↓` 减少。

## 存档与导出

- 「玩家存档」可新建、切换、重命名、复制或删除角色。导入人物卡会新建存档，不会覆盖当前角色。
- 「导出 PbDH」用于备份和继续编辑；需要分享成品时可导出 HTML 或打印 PDF。
- 打印 PDF 会打开浏览器打印窗口；在打印机选项中选择「另存为 PDF」。
- 浏览器内存档不是云存档。重要角色请保留 PbDH 备份文件。
