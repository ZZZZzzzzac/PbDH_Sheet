# ADR-0030: Static Web Without PWA or Server API

状态：Accepted
日期：2026-07-25

## 背景

ADR-0001 同时决定了静态 Web、无服务器 API 与 PWA 应用壳。当前产品已作为普通 HTTPS 静态站点发布，但代码没有 Service Worker、Web App Manifest 注册或 PWA 构建插件。Character Saves、System Package 缓存与偏好使用浏览器本地存储，并不依赖 PWA。

把未实现的离线应用壳继续写成架构事实，会让发布验证、用户预期和后续维护产生歧义。

## 决策

本 ADR 替代 ADR-0001：

- Base Framework 以 HTML、JavaScript、CSS 和静态 assets 的形式通过 HTTPS 部署；
- 不注册 Service Worker，不提供 PWA 安装入口，也不承诺离线刷新或重新打开应用；
- 不依赖服务器 API、账号、云同步、在线市场或后端数据库；
- IndexedDB 和 localStorage 继续提供浏览器站点范围内的缓存、角色存档、额外资源和小型偏好；
- System Package 来源可以是构建时预置包、本地 zip 或浏览器支持的本地目录；不支持远程 URL 导入；
- 跨设备恢复依赖显式导出/导入，浏览器本地数据不被描述为云备份。

## 理由

- 该决定与当前实现和发布产物一致；
- 静态部署保留低运维成本和明确的数据边界；
- 本地持久化已经覆盖正常编辑与自动保存，不需要用 PWA 解释；
- 若未来需要可靠离线能力，应以可测试的缓存、升级和恢复策略重新决策，而不是保留名义上的应用壳。

## 代价

- 断网后不能保证刷新或重新打开应用；
- 清理站点数据会丢失未导出的本地角色和导入缓存；
- 不提供多设备同步、在线包分发或远程 URL 一键加载。

## 后续信号

出现明确的离线使用需求，并能定义缓存范围、更新策略、存储配额和故障恢复验收时，重新评估 PWA。出现账号、跨设备同步或托管市场需求时，另行评估服务器 API，不能作为本 ADR 的隐式扩展。
